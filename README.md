# Software FJ – Sistema Integral de Gestión de Clientes, Servicios y Reservas

Proyecto de la **Fase 4 – Prácticas simuladas** del curso **Programación (213023)** de la
Universidad Nacional Abierta y a Distancia (UNAD).

Aplicación en Python con interfaz Tkinter para gestionar clientes, servicios y reservas de la
empresa Software FJ, sin base de datos y con manejo avanzado de excepciones.
